## Remaining publication steps

1. Save and inspect the genuine Bob task consumption summary. Bob completed its tests and review, and the usage statement describes that work. The existing work capture is not the required summary screenshot.
2. Upload `final-demo.mp4` publicly to YouTube using `YOUTUBE.md`. Add `NARRATION.srt` as English captions and verify the processed video.
3. Run `npm run submission:check`, push the final code and evidence to main, and confirm the public URLs.
4. Complete the hackathon form with the saved statements, cover, video and presentation. Verify the platform confirmation. The project is not submitted until that confirmation exists.
